# MeuBotFacebook

Projeto pessoal para organizar anúncios e preparar publicações para redes sociais.

## Objetivo da primeira versão
- Criar e editar anúncios
- Adicionar imagem
- Pré-visualizar a publicação
- Organizar grupos autorizados
- Registrar histórico
- Preparar integração oficial com a Meta, respeitando permissões e regras da plataforma

> A automação de publicação será implementada somente por meios oficialmente permitidos pela Meta.
